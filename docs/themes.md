# Светлая и тёмная тема

В личном кабинете откройте «Настройки интерфейса» и нажмите переключатель «Тёмная тема». Тема применяется сразу и автоматически сохраняется в вашей учётной записи. При ошибке сохранения возвращается прежняя тема и появляется сообщение. Остальные настройки интерфейса сохраняются своей кнопкой, независимо от темы.

По умолчанию используется светлая тема. Последний выбор кешируется в браузере, чтобы применить фон до загрузки приложения; после входа приоритет имеет настройка учётной записи. Выход не очищает кеш оформления страницы входа.

Палитра охватывает меню, таблицы, карточки, личный кабинет, административные разделы, диалоги, поиск пользователей, уведомления и чат ИИ. Сохраняются зелёные акценты, цветовые состояния и существующая геометрия интерфейса. Страницы PDF отображают оригинальный цвет документа; интерфейс стороннего редактора OnlyOffice управляется самим редактором.

## API и сопровождение

`GET /api/v1/me` возвращает `preferences.theme`: `light` или `dark`. Авторизованный `PUT /api/v1/me/theme` принимает `{"theme":"dark"}` или `{"theme":"light"}` и возвращает обновлённый профиль. Операция атомарно изменяет один ключ JSONB и не меняет компактность таблиц или стартовую страницу. Отдельная миграция не нужна.

Существующий `PUT /api/v1/me/preferences` также принимает необязательный `theme`. Если старый клиент его не передал, текущая тема сохраняется. Неизвестные значения отклоняются с HTTP 400. Пользователь изменяет только собственные настройки.

Семантические токены тёмной палитры объявлены в `frontend/public/theme.css`. В `style.css` прежние светлые цвета оставлены как значения по умолчанию для этих токенов. Новые компоненты следует оформлять через те же токены, сохраняя цвет бумаги в предпросмотре документов.
