# Карточка создания документа

В разделе **Администрирование → Типы документов** выберите тип. В блоке «Карточка создания» можно менять порядок общих реквизитов, их подписи и подсказки, скрывать необязательные поля и делать видимые поля обязательными. Название документа всегда отображается и обязательно.

Дополнительные поля можно упорядочить, распределить по разделам карточки, снабдить подсказкой и пояснением. Для поля «Пользователи (несколько)» автор документа отмечает сотрудников в списке; одиночный выбор остаётся доступен как «Пользователь».

Поля обоих пользовательских типов доступны в конструкторе маршрутов как источник исполнителей. Когда этап получает значение множественного поля, задача создаётся каждому выбранному сотруднику. Изменения карточки применяются к последующим созданиям и редактированиям документов этого типа.
