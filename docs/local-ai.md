# Тестовый локальный ИИ

В DocJet есть небольшой текстовый чат, который открывается кнопкой «Спросить ИИ» слева снизу после входа. Он отвечает на простые вопросы и пока не получает документы, карточки или данные пользователей автоматически. История остаётся в открытой вкладке и не записывается в базу.

Чат использует локальный [Ollama](https://docs.ollama.com/windows) на `127.0.0.1:11434` и модель [`qwen3:1.7b`](https://ollama.com/library/qwen3:1.7b). На компьютере с NVIDIA GPU Ollama может запускать эту модель на видеокарте. После установки официального клиента Windows загрузите модель:

```powershell
ollama pull qwen3:1.7b
```

Если приложение Ollama не запущено в фоне, сначала выполните `ollama serve` в отдельном терминале, затем `ollama pull qwen3:1.7b`. Проверьте использование видеокарты после первого ответа командой `ollama ps`: у модели в столбце `PROCESSOR` должно быть `100% GPU`. Модель загружается в память по первому запросу, поэтому первый ответ может занять больше времени.

API DocJet принимает не более 12 сообщений, ограничивает длину вопроса и ответа, не принимает системные сообщения от браузера и ждёт локальную модель не более 90 секунд. В этой временной версии нет поиска по документам, действий в системе и сохранения переписки.
