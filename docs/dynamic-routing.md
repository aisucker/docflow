# Динамические маршруты

Администратор создаёт маршрут в разделе «Маршруты», затем назначает его типу документа в разделе «Типы документов». Новый документ получает код маршрута при создании. Автор заполняет карточку и отправляет черновик в работу без выбора схемы. Для документов, созданных до этой настройки, используется текущий маршрут типа.

Для реквизита «Подписант», «Работник» или «Исполнитель» добавьте в тип документа поле с типом «Пользователь». В маршруте источник исполнителя можно выбрать из конкретного пользователя, группы, поля документа, автора или общего реквизита «Ответственный». Участники группы и значение поля определяются в момент запуска соответствующего этапа. Уже выданные задачи сохраняют своих исполнителей при последующей правке группы. Если источник пуст, пользователь отключён или группа неактивна, переход не выполняется и на странице документа показывается причина.

Этапы, отмеченные как запущенные параллельно с предыдущим, образуют блок. Все подходящие по условиям этапы блока получают задачи одновременно. Каждый этап завершается по собственному правилу: `all` ждёт всех назначенных людей, `any` — первого завершившего. Следующий блок открывается только после завершения всех этапов текущего блока. Возврат или отклонение из любой задачи завершает весь экземпляр маршрута и отменяет остальные открытые задачи блока.

Пример кадрового приказа: первый этап — подпись руководителя; следующий параллельный блок — ознакомление работника из поля «Работник» и исполнение кадровой группой. Состав кадровой группы можно менять без редактирования маршрута. Документ перейдёт в итоговый статус после ознакомления и исполнения.

Страница документа открывается по `/documents/{id}`. Вверху переключаются «Карточка», «Предпросмотр» и «Ход исполнения». Последняя вкладка показывает этапы, задачи, доступные исполнителю кнопки и историю. Предпросмотр в браузере поддерживает PDF; DOCX доступен для скачивания и через шаблоны.

Изменение схемы создаёт новую версию. Запущенный маршрут использует снимок версии и её кнопок; изменение маршрута или справочника кнопок не меняет уже выданные задачи.
