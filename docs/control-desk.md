## Границы и права

Личные записи хранятся на сервере и видны только владельцу, включая доступ администратора через тот же API. Связи и недавние документы проверяют актуальные права: удалённый или недоступный документ не раскрывает название и ID. Отметка просмотра — персональная отметка открытия карточки, а не юридическое подтверждение прочтения документа. Ознакомление с объявлениями фиксируется отдельным явным действием пользователя.

Напоминания показываются на рабочем столе, без email/push. Открытый рабочий стол обновляется раз в минуту и вручную. Списки ограничены: 1000 личных записей, 100 недавних документов, 200 открытых задач, 200 объявлений и 1000 строк административного отчёта. Подборки плоские, без вложенных папок. Запись может содержать одну ссылку на документ. Просрочка задач определяется сроком документа. По окончании публикации объявление скрывается, история подтверждений сохраняется. Изменение объявления не сбрасывает прежние подтверждения: для нового обязательного ознакомления создайте новое объявление.

Административные отчёты доступны только admin, ничего автоматически не переназначают и не удаляют. Наличие несогласованного типа без маршрута может быть допустимым: отчёт предназначен для проверки человеком. Очередь интеграций показывает до 500 событий, не раскрывая payload/секреты и не выполняя повторную отправку по кнопке.

API: GET /desk, /desk?part=recent, /desk?part=tasks; POST /desk/items; PUT/DELETE /desk/items/{id}; POST /documents/{id}/seen; GET /bulletins; POST /bulletins/{id}/ack; POST /admin/bulletins; PUT /admin/bulletins/{id}; GET /admin/control?report=... [&format=csv]. Все пути имеют префикс /api/v1 и требуют авторизацию. Запросы изменения требуют version для защиты от конфликтов.

Проверки: backend/control_test.go — изоляция личных данных, скрытие удалённых документов, чтение по ролям, расписание публикации, идемпотентность подтверждений, конфликты версий и все 9 SQL-отчётов с CSV. Полный backend проверен на отдельной одноразовой базе с DOCFLOW_TEST_DATABASE_URL и настоящим OnlyOffice Builder для существующих тестов генерации; Go vet и сборка TypeScript/Vite прошли.
