# Поручения в маршруте

На странице документа кнопка «Отправить по маршруту» находится в верхней панели рядом с «Обновить». На вкладке «Ход исполнения» текущие задачи пользователя показаны отдельными строками. Кнопка «Действия» открывает окно с действиями этапа и полем комментария.

Кнопка «Поручить» создаёт связанную задачу для выбранного активного сотрудника. Основной исполнитель сохраняет возможность выполнить свою задачу. Когда один из них завершает действие, вторая задача закрывается, а маршрут учитывает эту пару как одну обязанность. Для этапа с несколькими независимыми исполнителями остальные задачи продолжают ожидаться. Поручение, его получатель и результат видны в ходе исполнения и истории документа.
